# KADARI — Visual Asset Pack

## Purpose
This folder is the authoritative home for KADARI visual brand references and execution assets.

## Current approved visual direction
The current approved brand-board direction uses:
- graphite / near-black foundation;
- vivid teal / emerald accents;
- mint highlights;
- clean white / light neutral surfaces;
- strong modern sans-serif typography;
- real physical asset photography;
- camera / scan cues;
- structured Digital Twin overlays;
- clear relationship between physical object and digital intelligence;
- the mathematical signature `Σ(V × C)`;
- the line **Every asset. Accounted for.**

## Visual principle

**The physical asset remains the hero. Technology surrounds it, recognises it, evidences it and gives it intelligence.**

Avoid:
- insurance shields as the dominant motif;
- generic fintech gradients;
- crypto aesthetics;
- sci-fi hologram clichés;
- gold wealth-management styling;
- abstract lens/iris graphics unrelated to the actual capture workflow;
- dashboards as the primary brand image.
