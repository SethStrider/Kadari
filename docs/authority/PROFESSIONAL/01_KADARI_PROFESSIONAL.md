# KADARI Professional

## Purpose
KADARI Professional is for firms that manage, inspect, value, audit, reconcile, finance, recover or transact on physical assets **for clients**.

This is a distinct customer family, not an awkward extension of Business.

## Target customers
- accounting firms
- auditors
- insurance assessors / risk surveyors
- brokers
- valuers / appraisers
- business valuation firms
- M&A advisers
- due-diligence teams
- asset-finance providers
- banks
- repossession agents
- auctioneers
- insolvency / liquidation firms
- business-rescue practitioners
- estate professionals
- outsourced asset-management firms

## Core model
One professional firm gets one master console with multiple separate client workspaces underneath it.

Each client workspace remains permissioned and isolated.

The firm can switch between clients, run engagements, assign fieldwork, create reports and export structured asset data.

## Commercial principle
Price by **client workspace / engagement capacity / asset volume**, not per user.

Professional paid plans should include unlimited firm users.

## Engagement Mode
A Professional user can create a defined job such as:
- FY2026 Physical Asset Verification
- Insurance Revaluation 2026
- Business Valuation
- Estate Inventory
- Repossession Catalogue
- Auction Catalogue
- Due Diligence
- Asset Finance Inspection

Each engagement should define:
- client
- scope
- locations
- asset categories
- required evidence
- responsible people
- deadline
- expected assets where known

Progress example:
- 738 expected assets
- 629 verified
- 61 exceptions
- 48 outstanding

At completion, produce an Engagement Report.

## Catalogue Mode
Use cases include repossessions, estates, business closures, auctions, liquidations and sale processes.

Flow:
**Scan → classify → photograph → describe → value → organise → export**

Capture:
- item number
- photos
- description
- category
- make / model
- serial number
- condition
- location / room
- value
- notes
- Digital Twin reference

Exports should support:
- PDF catalogue
- Excel / CSV
- JSON / API
- auction / listing feed
- insurer / bank report
- valuation schedule
- transaction asset schedule

Future option: publish selected catalogue items to a controlled shareable page without exposing private internal data.

## Accounting / audit use cases
- book-to-floor reconciliation
- floor-to-book reconciliation
- year-end physical verification
- exception reporting
- evidence collection
- branch verification campaigns
- asset existence support
- audit-ready evidence packs

KADARI does not perform the audit or provide audit assurance. It supplies evidence, workflow and structured records.

## Insurance assessment use cases
- commercial contents inventory
- replacement-value evidence
- risk survey capture
- photographs and condition
- insurer / broker reporting
- renewal update rather than rebuild

## Business sale / valuation / M&A
Create a controlled asset schedule as at a defined date containing:
- identity
- condition
- location
- value
- evidence
- ownership / custody support
- finance / encumbrance information where available

## Asset finance / repossession
Support:
- pre-finance inspection
- periodic physical confirmation
- condition update
- refinance review
- repossession catalogue
- disposal / sale handoff

## Estate / insolvency / liquidation
Rapidly establish what physically exists, where it is, its condition and what evidence supports it.

## Professional positioning
**One platform for the physical asset work you do for clients.**

The goal is to convert repeated manual cataloguing, spreadsheet reconciliation and evidence collection into a reusable professional workflow.
