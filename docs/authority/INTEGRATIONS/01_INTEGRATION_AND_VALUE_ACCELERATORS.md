# KADARI — Integration & Value Accelerator Authority

## Integration thesis
KADARI should become the physical asset intelligence layer between the real world and the financial / operational systems that already run the business.

**Your accounting system knows the number. KADARI knows the asset behind it.**

## Priority accounting / ERP integrations
- Xero
- QuickBooks Online
- Sage
- Zoho Books
- Microsoft Dynamics 365
- NetSuite
- SAP
- Odoo

Additional regional systems can be added based on customer demand.

## Integration goals
Connect the accounting / ERP asset record with the physical Digital Twin.

Example:
Accounting system:
- CAT Excavator 320
- book value
- depreciation
- cost centre

KADARI:
- identity matched
- serial confirmed
- current condition
- current location
- custodian
- replacement value
- market value where appropriate
- evidence status
- Digital Twin confidence

## Value accelerators
These should be prioritised because they create disproportionate customer value without equivalent COGS.

### Book vs Reality Reconciliation
Compare the accounting register to physically evidenced assets.

### Ghost Asset Detection
Accounting record exists but no sufficient recent physical evidence exists.

### Unrecorded Asset Detection
Physical asset exists in KADARI but not in the accounting / ERP asset register.

### Depreciation View
Display book depreciation alongside current physical condition and relevant value views.

### Replacement Value Gap
Compare depreciated / recorded value with current replacement exposure.

### Insurance Gap
Compare insured value with evidenced replacement exposure where relevant.

### Valuation Freshness
Flag stale valuations.

### Condition Drift
Compare present condition against earlier visual records.

### Position Confidence
Show confidence quality across the Asset Position.

### Audit Pack
One-click pack containing identity, images, serial, financial record, condition, location, custodian and history.

### Year-End Verification Campaign
Run branch / custodian verification campaigns without rebuilding the register manually.

### Custody Confirmation
Allow employee / site manager confirmation of possession and condition from mobile.

### Depreciation Anomaly
Surface apparent inconsistencies for review without pretending to give accounting advice.

### Disposal Workflow
Physical disposal / sale event can initiate the downstream accounting workflow.

### Acquisition Workflow
Newly scanned purchase can create or suggest a corresponding accounting-system asset record.

### Document Matching
Match invoice / receipt to Digital Twin.

### Warranty Expiry
Surface upcoming expiries.

### Service / Maintenance Evidence
Retain operational history on the asset.

### Asset Movement Timeline
Track location and custody changes.

### Portfolio Heatmap
Show concentrations of asset value, stale evidence and attention requirements.

## Business value model
KADARI should connect three layers:

### Physical truth
What actually exists?

### Financial truth
What do the books say?

### KADARI intelligence
Where do they differ, and what needs attention?

## Tiering principle
Do not artificially cripple basic integrations. Use the pricing ladder to increase depth.

### Business Start
- CSV / Excel import-export
- basic accounting export

### Business
- Xero / QuickBooks / Sage / Zoho
- audit packs
- depreciation / book-value reconciliation
- valuation-gap intelligence

### Business Pro
- NetSuite / Dynamics / Odoo
- API
- multi-entity
- advanced reconciliation
- automated campaigns

### Enterprise
- SAP
- bespoke ERP
- SSO
- custom APIs
- data warehouse / enterprise feeds
- custom workflows

## Important boundary
KADARI provides physical evidence, workflow and intelligence. It does not replace the customer's accounting system, auditor, insurer or valuer.
